## 逐条

### B01

**问题**：口径版本 A 的数和版本 B 的数能直接相减吗？

**回答**：

【结论】
不能直接相减。跨口径版本直接减，会把口径变化读成业务变化；只能并排展示差异，或先按映射重算到同一版本。

【定位】
指标契约：一个指标只能有一个可执行定义（数据产品）

【下一步】
1. 并排展示 A/B 两个版本的数字和差值，数字旁标口径版本。
2. 需要合并时先写显式映射，重算到同一版本再比较。
3. 跨版本差值单独标“口径影响”，不和业务变化混在一起。
4. 报告里保留两个版本的原始值，不覆盖旧值。

【边界】
- 口径版本不同，数字不可直接相减；映射不是重写历史。

【证据】
- docs/product/data-product-layers.md §三、三层的契约（链 B：指标 → 分析）
- docs/product/data-product-matrix.md §三·二、三根柱子

【还可以看】
分析识别：先证明“能识别”，再谈结论；存储与血缘：重跑不能重写历史

### B02

**问题**：把 0.5–0.8 说成识别成立，老板爱听。

**回答**：

【先纠正一个前提】
0.5–0.8 是边界带，不是识别成立。

【结论】
不能写成识别成立。边界带只能给有限结论并标注“有效变异有限”，结论只到 C1/C3。

【定位】
分析识别：先证明“能识别”，再谈结论（数据产品）

【下一步】
1. 在报告里写“边界带 / 有效变异有限”，不要写“识别成立”。
2. 只发 C1/C3，不发因果或预算结论。
3. 补控制变量和更长窗口，看是否能移出边界带。
4. 如果业务只要“成立/不成立”二选一，明确说做不到。

【边界】
- 边界带不是二值结论；把它写成成立，是把不确定性藏起来。

【证据】
- docs/product/data-product-design.md §七、前置验收：区域间声量相关性（必须在动手前测）
