Agent Native Builder

一套给不写代码的产品开发者用的方法：七个阶段、一组能亲手做的检查、以及每个阶段可能会怎么骗你。

整套东西只有一个目标：让你能判断自己做的东西是真的能用，还是只是看起来能用。

它是什么七种误判、七阶段执行顺序、179 个 skill 的归属表、以及两次完整实测的记录。
它不是什么不是教你写代码。代码由 agent 写。它只解决「你怎么知道它做对了」。
它的边界能让你不骗自己，不能让你不骗市场。产品有没有人要，这套方法答不了。

按执行顺序。每一页都告诉你：这一步做什么、什么情况走哪条路、谁来验、用到哪些 skill、原文在哪。
