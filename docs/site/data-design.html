数据产品设计：声量 → GMV 归因

以 Momcozy 区域声量归因 为真实案例：如何用 8 层 + 3 柱方法论，将模糊的「看声量投广告」需求转化为可检验、可证伪、有置信区间的量化决策模型。

设计顺序铁律：自顶向下（与建造顺序相反）。
结论层 → 指标层 → 打标层 → 采集/存储 → 呈现/报告。
理由来自试跑实测教训：自底向上建到一半才发现底层数据支撑不了上层决策，是数据产品最昂贵的死法。

一、三个关键的前置发现

F1 缺少预算自变量

痛点：决策是分配资源，但当前只有 GMV + 声量数据。

能算出「声量 → GMV 弹性」，但算不出「预算 → 声量成本」。决策者拿到弹性依然不知道往哪投，因为弹性高可能获客成本极高。解决：必须补齐按区域×渠道的花费数据才能做 C4 边际回报。

F2 面板固定效应吸收趋势

痛点：声量与 GMV 均随时间上升，单序列必然产生 0.9 的假相关。

决策单位是「区域」，问题转化为区域 × 周的面板数据。引入周固定效应整体吸收全球增长趋势与算法变动，识别变异集中在「同周内 A 区域声量超常增长是否带来 GMV 超常增长」。

F3 全球效应不可识别

痛点：周固定效应消除了伪相关，但也吸收了全球共性变化。

一次全球品牌大事件或平台大促的影响无法被模型归因到特定区域声量上。这是模型的前提约束，必须在结论卡中明确声明。

二、四级结论卡体系 (C1–C4)

数据产品最终交付的是「结论」，而非裸数据看板。每条结论必须包含可证伪条件与动作建议。

结论层级回答的商业问题交付物与指标失效与证伪条件
C1 基础关联与存在性区域声量与 GMV 之间是否存在统计显著的正向关联？弹性系数 β 估计值、95% 置信区间、样本量与观测周数当置信区间跨 0，或控制促销/缺货变量后 β 降为 0 时，本结论失效，停止归因。
C2 时滞与衰减周期声量增长后，GMV 在第几周达到峰值？影响持续几周？滞后 1~4 周各期的弹性系数与脉冲响应曲线当滞后各期系数均无统计显著性时失效。
C3 区域差异与弹性对比哪些区域属于「高声量敏感型」，哪些属于「低响应型」？分区域的弹性分档表（高/中/低）与基线规模对照当区域分类在连续两季度波动变动超过 50% 时失效。
C4 预算边际回报决策在各区域追加 1 万元预算，预计分别能撬动多少增量 GMV？区域边际投入产出比（ROI）与推荐预算增减分配比例当未获得各区域真实获客成本/投放花费数据时，C4 不做产出。

三、计量模型与识别策略

为剔除季节性与全球大盘趋势干扰，模型采用双向固定效应面板回归：

ln(GMV)_{r,t} = β · ln(声量)_{r,t-k}
              + 区域固定效应 α_r        ← 吸收区域规模、成熟度与基线差异
              + 周固定效应   λ_t        ← 吸收全球大盘趋势、季节性与平台算法变动
              + 控制变量     X_{r,t}    ← 促销折扣、价格变动、断货天数、竞品大促
              + ε_{r,t}
