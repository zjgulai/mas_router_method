Skill 全表

110 个 skill，按七阶段归属。每个都标注了来源、用在哪一步、以及它坏了会怎样——最后一项才是你真正要用的。

先说清一件事：同一件事有三种"没有"。 「.claude/skills/ 里没有」不等于「不存在」，也不等于「你调不到」。这三个问题的解法完全不同。

本页第三列标来源：仓库 直接按名字调用；插件 调用时要带前缀，如 anthropic-skills:agent-browser；ANB 是本方法新增的。

如果某个 skill 你调不到，正确结论是「我这台客户端没装这个插件」，不是「这个 skill 是假的」。
