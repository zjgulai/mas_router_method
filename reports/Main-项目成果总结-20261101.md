## 2. 架构：一条依赖方向，两个 surface

```
apps/workbench ──┐
                 ├──→ packages/core ──→ packages/shared
apps/bot-gateway ┘         │
                           └──→ packages/feishu
packages/evals ──→ packages/core, packages/shared
packages/consult ──→ 便携知识 bundle（自包含）
```

- 依赖只能单向：`shared ← core ← apps`，`evals → core/shared`。
- `packages/shared` 是唯一 schema 层，不 import 仓库内任何包。
- 两个 surface（workbench、bot-gateway）只调用 runtime，不互相 import。
- 该边界由 10 篇 ADR 固化：`docs/adr/0001`（Agent SDK 作为 runtime）、`0002`（schema 层拥有领域对象）、`0003`（工具失败是值）、`0004`（headless 权限模型）、`0005`（模型与预算策略）、`0006`（持久化与保留）、`0007`（视觉分析供应商）、`0008`（工作流版本）、`0009`（品牌隔离）、`0010`（Main Agent 共享状态）。

## 3. Recipe Agent：从爆款视频到可执行 Recipe

### 3.1 产品定义

输入一条 TikTok 爆款参考视频，产出一份 **Recipe**：该视频的可克隆抽象，重新绑定到一个品牌——hook、节拍、口播、字幕公式、音频方向（见 `GLOSSARY.md`）。人是审阅单位，摄影师是执行单位。

### 3.2 已交付（已验证）

| 模块 | 内容 | 测试 |
| --- | --- | --- |
| `packages/shared` | 领域对象唯一真源：Recipe、Reference、Analysis、Run、Brand 全部 Zod schema，持久化边界校验 | 随 core 覆盖 |
| `packages/core` | `run-agent.ts` 单文件 agent 循环：模型调用、步骤记录、预算执行（`maxBudgetUsd` + 循环内双重检查）、取消、成本核算（读 `modelUsage`）；工具走端口接口（`BrandStore` / `ReferenceStore` / `RecipeStore` / `VisionAnalyzer`）；SQLite + vod 适配器；4 个种子品牌 | 32 |
| `packages/evals` | 14 案例 harness + 15 条确定性规则 + rubric judge（已接 LLM，待 key）+ 基线快照机制 + 护栏案例（release blocker） | 105 |
| 工具失败契约 | `ok()/err()/guard()`：失败是值不是异常，模型可见失败并可重试（ADR-0003） | 随 core 覆盖 |

## 4. Main Agent：方法文档变成群里可用的咨询 Agent

2026-10-29 交付。对象：`packages/consult`（咨询引擎）+ `apps/bot-gateway`（飞书入口）。完整验收与限制见 `docs/product/main-agent-capability-graph.md`。

### 4.1 能力图谱（packages/consult）

- 四条轴、20 个节点、17 条症状路由：生命周期（7+1）、数据产品层（8）、横切三柱（口径/质量/血缘）、Agent 交付（7 阶段 + 四车道 + G1–G5）。
- 检索：1128 个 chunk 的 BM25（CJK bigram + 英文词），源自 115 个仓库文档的便携快照。
- 回答契约：六段固定结构——【结论】【定位】【依据】【下一步】【边界】【证据】；置信度 low 时追问，不包装成确定。
- 直接 plays：错误前提先纠正、冲突约束先给取舍、无依据直接拒答并给可问范围。
- 58 个测试：图谱完整性、语料、14 个 canonical 问题路由、越界拒答。

### 4.2 飞书网关（apps/bot-gateway）

- 双模式：WebSocket 长连接（默认）+ HTTP webhook（`POST /events`）。
- 事件序列：验签/解密 → 归一化 → 幂等（`event_id`，TTL 10 分钟）→ 准入 → per-chat 队列（全局并发 2、同群串行、3 秒内回执）→ `agent.answer()` → 回复失败降级。
- thread session：SQLite 持久化，TTL 30 分钟、最近 6 轮。CLI：doctor / configure / authorize / eval。45 个测试。
- `packages/feishu`：验签、解密、事件归一化、post 富文本、mention open_id。24 个测试。
